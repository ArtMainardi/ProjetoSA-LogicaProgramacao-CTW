# Sistema de Controle de Equipamentos e Manutenções Industriais (Projeto SA)

Este é um sistema computacional desenvolvido em **Java** focado em centralizar, automatizar e organizar o controle de dispositivos e manutenções ocorridas dentro do setor produtivo industrial. A aplicação substitui registros manuais por uma solução robusta orientada a objetos.

## 🚀 Funcionalidades

O sistema opera em modo texto (Console) e é dividido em quatro módulos principais:

1. **Gerenciamento de Equipamentos:** Cadastro, consulta, alteração, exclusão e listagem de máquinas e dispositivos.

2. **Gerenciamento de Técnicos:** Controle e cadastro dos profissionais responsáveis pelas manutenções.

3. **Controle de Manutenções:** Abertura, andamento e finalização de ordens de serviço (Preventivas ou Corretivas), com atualização automática de status do equipamento.

4. **Relatórios:** Quantitativos gerais de cadastros, equipamentos por status e quantidade de manutenções ativas/encerradas.

## 🛠️ Tecnologias e Conceitos Aplicados

- **Linguagem:** Java 21
- **Persistência em Memória:** Estruturas de dados baseadas em `ArrayList`.
- **POO & Arquitetura:** Separação clara de responsabilidades utilizando camadas de Modelo, Repositório e Serviço.
- **Tratamento de Exceções:** Uso de `try-catch`, `throw` e exceções customizadas (ex: `SwitchCaseException`) para validação de regras de negócio.

## 🔄 Metodologia de Desenvolvimento (Git Flow)

Para a organização e versionamento do código no GitHub, foi adotada a metodologia Git Flow:

- **main:** Ramo contendo o código de produção estável e finalizado.
- **develop:** Ramo principal de integração das funcionalidades onde os testes foram consolidados.
- **feature/\*:** Ramos temporários criados especificamente para o desenvolvimento de cada módulo isolado (ex: `feature/modulo-equipamentos`, `feature/modulo-tecnicos`), posteriormente integrados via Pull Requests.

## ☕ Como Executar

Certifique-se de ter o JDK 21 instalado na sua máquina.

### 1. Clone o repositório

```bash
git clone https://github.com/ArtMainardi/ProjetoSA-LogicaProgramacao-CTW
```

### 2. Abra o projeto

Abra o projeto na sua IDE de preferência (VS Code, IntelliJ IDEA, Eclipse, etc.).

### 3. Execute a aplicação

Execute o arquivo principal localizado em:

```text
src/projetoSA/Main.java
```
